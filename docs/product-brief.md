# IMStage — 产品说明

状态：2026-09-23。Agent 生成与 AI 编辑是核心，手动编辑与渲染为支撑能力。官网 imstage.org 使用 Vercel 前端与持久化账号/Agent 服务器；独立认证的 MCP 服务已部署。计费未实现。本轮创作体验修改与上线验收分别记录，不能把本地实现当成已部署。

## 定位

专业开源的聊天场景创作工具。官网优先展示产品效果与商业使用场景，下拉即可了解 ChatGPT 接入。核心场景包括产品演示、教学、叙事素材与合成评测数据。

## 用户提出的能力

- Web 以对话交互开始，左右布局呈现输入与预览，允许自然语言反复修改。
- 将不同 IM 平台的界面元素抽象为可配置模板和变量；支持单聊、群聊、人物头像、消息时间、手机时间及状态。
- 覆盖文字、图片、语音、视频、定位、加好友提示、系统提示，以及模拟红包和转账卡片等消息类型。
- 支持保存用户头像偏好，默认普通截图，并可选择长截图。
- 允许上传已获授权的截图或图片，多模态提取为可编辑的结构化内容，再进行修改和渲染。
- Web 与 MCP/API 复用程序化渲染能力；未来支持在 ChatGPT 和 Claude 内调用并展示生成结果。
- 按需接入图像生成、视频生成和搜索能力。

## 开源与托管方向

用户希望项目开源、Web 免费可用，并对托管 MCP/API 采用充值 key 模式。具体免费额度、渲染与 AI 成本的计费边界、key 生命周期、定价及支付供应商均未确定。先保留这些决策，不在初始化阶段接入计费。

## 当前核心链路

用户一句话／截图 → DeepSeek Agent 理解需求 → 调用 create_scene、upsert_message、delete_message、generate_image → 校验并更新共享 Scene → 实时预览与 PNG 导出。工具结果回传模型继续执行；实际执行步骤可展开查看。UI 为左侧创作 Chat、中间渲染画面、右侧可展开的 Vibe Edit；点选消息带入严格局部编辑范围。

React + Vite、Node + SQLite 账号会话已实现。密钥仅由后端读取。图像模型与 DeepSeek 分开配置，未配置或调用失败必须明确显示，不能以静态示例代替真实生图。MCP 已复用相同 Scene 与渲染路径，但使用独立的实例数据库和认证令牌。

## 2026-09-21 核心 Web 与账号实现

已实现登录／注册、服务端持久会话、我的作品、保存冲突处理、账号隔离、改密和退出。账号采用当前实例的 SQLite + Node crypto，Web 仍为 React + Vite。作品编辑与预览/导出复用既有 Scene 模型；免登录草稿保留在当前浏览器；登录后的创作会话会自动同步 Scene，AI 聊天记录仍属于本机会话。未配置邮件验证/找回或 OAuth，不把自托管运行写成公网服务已上线。详细流程与配置见 [core-web-auth.md](core-web-auth.md)。

## Agent 验收与边界

主入口 `/#/create` 和账号新建作品使用真实 Agent。首页提供明确标记的合成示例，滚动展示直接编辑与人物变体，不在浏览时调用模型。支持六种平台皮肤和文字、图片、定位、系统、联系人、转账、语音卡片、视频缩略图、链接、相册。语音播放与视频生成未实现；这些卡片只用于静态截图。图片服务支持 OpenAI-compatible `images/generations` / `images/edits` 和腾讯云 TokenHub WAND-Vega 异步任务；凭据只由服务端读取，必须通过实际调用才算可用。参见 [Agent 服务说明](../services/agent/README.md)。

## 项目、自由编辑与截图评测

账号作品可归属一个项目，项目保存规则和默认平台，批量任务按提示词 × 平台生成独立作品。规则由服务端读取和快照，不能把模型遵循规则的能力当作确定性保证。

结构化 Scene 支持人物、消息、背景、颜色、尺寸、圆角、时间和设备外观编辑。同一 Scene 切换平台只改变渲染。原图精确编辑使用 Scene.reference 编辑层，通过同一 Agent runtime 调用 OCR、局部观察、图片服务和渲染工具；Web 预览、导出与 dataset benchmark 共享编辑层 HTML 和文字排版实现。原图模式不等于整张截图已自动拆成所有可编辑元素，跨平台须重新生成结构化场景。

当前验收事实见 [agent-project-acceptance.md](agent-project-acceptance.md)。完整 11/11 尚未通过。2026-09-21 腾讯云 WAND 文生图与传入原图的参考编辑已通过真实 DeepSeek 工具调用；不得据此表述为截图数据集全量通过。

## 创作会话管理

`/#/create` 支持独立会话的新建、命名、搜索、复制、删除和切换。每份本机会话保存画面、AI 记录、参考图、未发送内容和截取位置，旧标签页草稿自动迁移；多标签页冲突不会静默覆盖。会话历史仅存当前浏览器，账号“我的作品”仍只保存 Scene。实现与验收见 [session-management-acceptance.md](../design/session-management-acceptance.md)。

## 2026-09-30 安全与定位变更（覆盖历史计划，水印/渲染部分由 2026-10-02 更新）

本节记录用户授权的新要求，**优先于本文档及 design/BRIEF.md 中任何冲突的历史计划**（水印与界面渲染两条由下节 2026-10-02 更新覆盖，其余仍然有效）：

- 定位改为**合成聊天测试/评测数据集与标注创作**，不再面向“逼真截图仿制”。官网首屏、用例、FAQ、文档与页脚须反映该定位。
- 所有预览与全部 PNG 导出（含裁切与 MCP 渲染）**默认**显示「AI生成 / 虚构」水印（2026-10-02 起可在项目/画面中关闭，见下节）。
- **移除**支付/转账/红包/余额类消息能力（UI、Agent、服务端）；遗留或导入的支付场景被中和为系统提示，不删除已存作品。
- **移除**公开的真实截图编辑/上传入口；API/MCP 的参考场景编辑与旁路（模板/导入/直连端点）全部拒绝。内部离线评测工具保留截图研究代码，但公开不可达。
- 渲染改为**通用 IMStage 聊天界面**（2026-10-02 起恢复各平台模板皮肤，见下节）。
- 中英双语使用条款与隐私/留存说明进入页脚与注册流程；禁止伪造证据、欺诈、诽谤、冒充与误导。托管生成写入最小化持久审计（运行 id/时间/账号/策略版本/状态/场景哈希），保留 90 天并真实清理；匿名本地编辑与导出无服务端审计（须如实记录该局限）。
- README（中英）加入 GitHub 免责声明：仅供测试/学习、禁止商业用途、反滥用。许可证改为非商业源码可得许可（LICENSE），历史 MIT 文本保存在 LICENSE-MIT-LEGACY；不追诉历史版本，不宣称 OSI 开源。
- 商业授权（闭源数据集/评测服务）只保留邮件咨询入口，使用集中配置（VITE_BUSINESS_EMAIL）；邮箱未核实前显示“暂未公布”，不得编造地址。

## 2026-10-02 项目模板与可选水印（覆盖上节水印/渲染两条）

用户最新明确要求：创建项目时可选择**是否加水印**、可选择**微信/WhatsApp 等平台模板**并**看到全部模板**。这是真实行为而非外观开关：

- `Project.watermarkEnabled`（布尔，默认开，旧项目迁移为开）随项目创建/更新/读取持久化；`Scene.watermarkEnabled?`（缺省=开）为 `false` 时，React 与确定性 HTML/PNG 渲染均隐藏水印与自定义 watermark 文字。`Scene.watermark` 文字保留兼容。开关属于用户偏好：模型工具不能修改（create_scene 保留、update_element 拒绝），关闭只影响新作品/所选作品，不改写已保存作品。
- 项目创建/详情提供**真实可选模板卡片**（IMStage 通用 + 微信、WhatsApp、iMessage、Instagram、小红书、Slack），使用共享合成样例的真实 SceneView 小预览，带水印即时开关；渲染恢复平台专属气泡/头像/输入栏样式，确定性渲染器同步存在平台差异；均为合成内容风格预览，不做商标/像素级克隆。支付中和、参考截图禁用、审计、认证与非商业许可等上节其余限制不变。
