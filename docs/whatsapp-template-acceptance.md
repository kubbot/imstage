# WhatsApp 模板选择与时间排版验收

2026-10-04 用户要求：明确指定 WhatsApp 时，Agent 自动选择对应模板；截图时间符合平台消息气泡布局。

## 改动

- 新增 `select_template({platform})`：完整七平台枚举、参数校验、真实无变化反馈；支持全局与 `@scene`，拒绝单条消息/人物的局部切换。保留内容、素材、设备和水印设置，清除遮盖模板的自定义布局。
- Agent 首次创作也按本次明确平台要求先选模板再 `create_scene`。无平台要求时沿用当前/项目/手动设置；重建仍保留已选平台。兼容 `update_element` 修改平台时同步清除布局。
- WhatsApp 文字气泡以等宽隐藏占位为末行时间/回执留出空间；可见元数据位于气泡右下角。短句共享末行，长句与显式换行不覆盖正文。空时间的接收消息无空元数据；仅发送消息显示回执。其余类型沿用独立元数据。
- React 预览/PNG/MCP 共享组件与确定性 HTML 渲染同步修复。更新服务端渲染版本，旧 PNG 缓存失效。

## 本地验证

- `npm test`：634/634 通过；`npm run build`（含 typecheck）、`npm run build:mcp` 通过。
- Playwright 定向验收 5/5：共享 React 和确定性 HTML 的正文/时间几何关系；短句同一行、长句/换行不重叠、空时间、单聊接收方无回执、自定义布局、微信回归；真实编辑器工具事件流切换、1440/390 px、刷新保持、实际 PNG 下载；已有平台选择/撤销与 PNG 用例。
- 编辑器有页面内容、无错误覆盖层、无 `pageerror`、无横向溢出；截图与实际下载 PNG 已人工查看。
- 真实 DeepSeek：原始提示词 `生成一个 和 Andrej Karpathy 聊天的 Whatsapp` → `select_template` → `create_scene` → 两次头像生成，最终 `ok:true`，WhatsApp，7 条消息。第一次只加载文字服务的测试在头像服务缺失时正确报告未完成，补齐现有图片配置后的完整调用通过。
- 真实模型与图片调用的输出及图片保存在忽略目录；不提交凭据、账号配置或模型原始日志。
- Browser 技能不可用，使用项目 Playwright 和本机 Chrome；Safari/Firefox 未测。
