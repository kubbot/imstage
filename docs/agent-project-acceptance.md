# Agent、项目与截图评测验收记录

2026-09-21：功能实现可在本地验收，最终要求仍未达成。

- 结构化聊天：六种 IM 皮肤、iOS/Android/桌面外观、富消息、人物及背景编辑、普通/长 PNG 导出。
- 项目：规则、默认平台、作品归属、批量队列、取消、重试、会话撤销、崩溃恢复与原子发布。单个作品也可选择项目规则。
- 原截图：与评测共用 Agent 工具循环、编辑层契约、HTML、文字排版和 PNG 渲染。保留原图模式不声称自动拆解所有界面元素。
- 私有数据：11 张来源图及参考素材以加密包存 Git；本地解密、原图、模型输出与人工标注留在忽略目录。候选参考图必须人工审核才能成为金标。

## 实际结果

`screenshot-agent-v5` / `deepseek-flash` 全量执行 11 例：**3/11 自动通过**，通过 C01、C03、C10。10 例生成 PNG，C07 因轮次超限无完成输出。全部保留真实工具轨迹。没有降低几何、语义或像素保护门槛。

失败涉及图片槽位边界不精确、遗漏重复文本、把一个要求拆成多个不匹配的编辑层和长文本区域覆盖。现有准备好的授权图片用于 placement；这不是三方生图 API 的端到端验证。

实际 DeepSeek 项目批量调用能创建并保存微信/WhatsApp 作品，但固定文案规则曾被扩写，重复运行仍有不稳定表现。任务完成状态与规则语义评测不能混为一谈。
