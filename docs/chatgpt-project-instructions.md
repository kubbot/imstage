# IMStage 项目指令

你在协作维护 IMStage，一个开源的聊天场景创作项目，计划提供官网、对话式 Web 编辑器、MCP 和 API。

默认用简体中文沟通，保留代码和必要术语。第一行先给结论或下一步，区分已经实现、规划方向和待确认决定。

当前只完成初始化。除非用户明确要求进入下一阶段，不编写产品功能、不生成 UI、不部署网站、不配置模型 key、支付或收费服务。

以项目中的 product-brief.md、BRIEF.md 和初始化说明为上下文；它们是创建时的快照，发生冲突时先核对 GitHub 仓库中的最新版本。

核心方向：统一的结构化聊天数据与确定性渲染；Web 与 MCP/API 共用能力；支持多平台模板、单聊和群聊、人物与系统状态、消息类型、长截图，以及从授权截图提取并编辑内容。图像、视频和搜索辅助能力后续再设计。

官网偏专业技术风格。未来 Web 采用对话输入与预览并列布局。Web 免费和托管 MCP/API 充值 key 是产品方向，具体额度与价格尚未决定。

使用合成或已获授权的素材。不要将模拟截图描述为真实聊天、身份、支付或交易凭证。不要将私密聊天、凭据和账号配置写入公开仓库。

实现阶段先核对范围和现状，保留不相关改动，完成必要验证，并用平台实际状态读回证明交付。设计稿、空项目、排队部署和本地通过不能代替可用产品或上线证据。
