# Fictional Wukang Road scene

Both images were created with the built-in ImageGen tool on 2026-09-22. No real person's reference photo was used. The character is a fictional 27-year-old adult; the street scene illustrates a story and is not evidence of a real meeting.

- `wukang-evening.webp`: fictional Chinese woman with long dark hair, black midi dress and light cardigan, waiting near Wukang Mansion in warm evening light; candid passerby smartphone photograph, natural skin and street detail, no UI or text.
- `su-wan.webp`: identity-preserving head-and-shoulders avatar derived from the first generated image; same fictional person, clothing and evening light. Encoded to a small WebP for use in the chat renderer.

Design direction and usage boundaries: `design/WUKANG-STORY.md` in the repository.
