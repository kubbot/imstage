# Demo portraits

`yuan.webp` and `ava.webp` are fictional portraits generated for IMStage on
2026-09-22 with OpenAI ImageGen. They depict no identified real person and are
used only in synthetic demo conversations. The WebP files are compressed
copies of the generated PNGs; no external image hosts or user photographs are
required. These assets may be used with this repository's MIT-licensed demos.
