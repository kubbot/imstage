# IMStage：对话创作台

2026-10-14。用户授权官网与 Web 全面改版、反复打磨和生产交付。此前“不做整体重设计”的历史范围由此次明确授权覆盖；产品能力、安全政策、数据和接口边界保持有效。

## 产品不变量

访客是准备合成测试、评测和教学样本的研究者与创作者。困难是把一段设定转成可控、可编辑、可复用的聊天场景。首屏应让人理解“输入设定 → 修改对话 → 导出素材”，体验创作的掌控感并开始真实任务。核心证据是实际 SceneView、同步编辑及同源 PNG 渲染，不能换成广告图或虚假 AI 演示。

## 设计树与视觉选择

- D1 A：对话创作台。场景像放在桌上的创作材料，主样本与正在修改的台词同处一张桌。温暖中性色、原有暖红、墨色文字；反参考是常见 SaaS 大标题加等大功能卡片。
- D1 B：评测样本档案。以固定设定、样本差异和档案秩序作为主叙事；反参考是后台数据表。
- D2 A1：先看到并试改一个真实样本，再了解受控变体、场景库、实际导出与接入。A2：先用场景库选择再进入试改。选择 A1，第一屏已有明确输入与输出，避免先浏览分类。
- D2 B1：先总览样本 A/B/C，再深入一条。B2：先展示差异比较，再展开档案。保留 B1 作为挑战方案；它更适合已有上下文的评测人员。
- D3：`apps/web/design/taste.html?direction=a|b` 是真实渲染组件组成的比较原型，包含首屏、代表中段和 390px 自适应。它不是生产流程，也不调用模型。

相对比较 A vs B（-2 到 +2；非绝对品质评分）：产品机制 +2，因为 A 在首屏显示实际编辑字段；五秒理解 +1，因为输入与输出相邻；自身辨识 +1，因为编辑纸笺与真实场景形成创作桌；结构区分 +1，因为后续导出与场景库使用不同构图；情绪准确 +1，因素材与工作桌对应创作任务；可行性 0，二者均复用现有渲染器；无障碍/性能风险 0，两者均可用原生布局与短过渡实现。

选择 A，并保留 B。回退条件：编辑笺遮挡必读内容、首屏下一步不明确、手机需要缩小页面才能使用。原型 A 的手机首屏输入可用，但桌面式叠放不能直接移植到触屏；生产移动端必须将纸笺放回文档流。不移植 Ambi 的水面 shader、强模糊和滚动锁定，它们对频繁编辑没有实际收益。

## 参考机制

- [Ambi](https://www.ambi.ai/en)：材质、文字、图像和运动的共同语义；改进其可读性与尽早兑现价值的空间。
- [Linear](https://linear.app)：将实际产品行为作为证明，日常工作界面控制密度。
- [Figma](https://www.figma.com)：创作空间与实际成果相邻。仅借鉴机制，不复制完整品牌视觉。

UI/UX 本机检索确认 44px 触控范围、文字对比、明确字段标签与 reduced-motion。泛化检索的蓝色/绿色、Fredoka 建议不适合现有品牌，保留 IMStage 暖红与 Syne/中文系统字体。

## 实施与验收

1. 官网：真实创作桌首屏、同步试改、紧凑原生滚动、受控变体、场景材料库、主题一致的真实 PNG 展示、ChatGPT 接入和必要说明。
2. Web：一致的语义颜色、边框、圆角、文字层级；创作 Chat 保持主要操作区域，预览/工具/属性明确分工；模板、项目、账号、接入、文档一起校准。不要给每日工作界面加入营销动画。
3. 保护会话、撤销、保存、平台选择、水印偏好、错误/加载/空状态与全部政策边界。不改后端协议，不新增付费服务。
4. 检查中文/英文，320/390/768/1024/1440px，浅/深/系统主题、键盘焦点、44px 触控、减少动效，实际编辑→导出与工作台接续。新增回归测试覆盖实际新行为，不测试装饰 CSS 数值。
5. 独立审查，修复确认的问题，当前 PR head 的 CI 与 Vercel 检查、合并及线上变更验收。截图和正式记录保留在任务证据中，可重建测试产物随后清理。

## 判断边界

功能通过不能证明品味已经超过 Ambi。交付依据是可对照的视觉改进、真实任务完成和审查结果；最终用户偏好和独立用户识别需要实际反馈，不能自评分为 9.8/10 后宣布超越。
