# IMStage — 核心创作体验

2026-09-21 用户明确：Agent 是核心，手动编辑是补充。本轮按这一产品要求重组界面。

- 左侧 **创作 Chat**：一句话、粘贴截图或上传图片即可开始；平台有默认值，可选其他 IM。
- 中间 **渲染**：共享 Scene 的实时画面，普通截图与长图共用同一渲染路径。
- 右侧 **Vibe Edit**：点选消息后展开对话编辑浮层；可切换全局编辑，手动字段折叠。
- 工具步骤真实反映后端执行；生成失败、部分结果、取消和图片服务未配置均有明确状态。
- 生成与保存互斥，保留修改历史、同标签页恢复和导出；手机通过 Chat／画面切换、浮层编辑适配。
- 延续已有克制的中性色、暖红主色和 light/dark/system；不为业务工作台套用营销页布局。

历史官网设计见 REVIEW.md。MCP、视频生成、语音播放仍按独立范围推进，不展示虚假已实现状态。

项目入口管理规则与批量作品；创作 Chat 可选项目。右侧元素编辑保留展开状态，支持人物、消息、界面背景与外观。原截图保留模式展示同一渲染器的编辑层，普通结构化模式展示可切换平台的 Scene。

## 左侧优先布局（2026-09-21）

创作 Chat 是主要操作区域：桌面默认 480 px，可拖动调整并记住宽度。会话入口在顶部，人物与项目设置折叠，对话与输入获得主要空间。右侧元素属性默认关闭，点选时展开；中等窗口使用浮层。手机保留创作 / 画面切换。错误提示位于顶部，不遮挡输入和发送。验收见 [creation-layout-acceptance.md](creation-layout-acceptance.md)。

## 2026-09-30 安全与定位变更（覆盖历史设计）

用户新要求优先于本文件历史内容：产品是**合成聊天测试/评测数据集标注**创作工具，不是逼真截图仿制工具。强制「AI生成 / 虚构」标识（不可关闭）、移除支付类消息、停用真实截图参考编辑、通用 IMStage 聊天界面（无平台商标/克隆）、条款与隐私（含 90 天审计留存与本地行为无审计的局限）进入页脚与注册、非商业源码许可 + 邮箱咨询的商业授权。设计延续现有克制中性色与 light/dark/system，不做整体重设计。详见 docs/product-brief.md 2026-09-30 一节与 docs/safety-policy.md。
