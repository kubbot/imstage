# IMStage — Open Design 简报

**原始初始化简报；用户已后续授权独立 Eval 工作台实现，并要求改为便签式输入。以下官网方向仍保留为初始设计背景。**

## 项目

IMStage：开源聊天场景创作工具。未来通过自然语言生成和编辑结构化对话，再由统一程序化渲染器导出模拟截图。

## 后续设计方向

- 专业技术风格，内容清晰、排版克制，避免过度装饰。
- 官网包含产品定位、示例、开源入口，以及进入 Web 和接入 MCP/API 的路径。
- Web 主要界面为对话输入与实时预览并列，支持逐步修改、导入图片与导出。
- 平台、人物、消息、系统状态是可编辑对象；完整考虑空白、加载、失败、重试和导出状态。
- 用户素材采用合成或已获授权的内容；模拟性质应在后续设计中清晰表达。

## 暂未决定

品牌 logo、色板、字体、组件库、首批 IM 平台和页面细节。本轮不要替用户生成或锁定这些方案。

## 文件与交付

此目录是未来设计简报与 handoff 的来源。后续设计产物应明确标注草案或已评审状态，与生产实现分开记录。本轮仅保存这份简报和项目说明。

## 已接受的 Eval 交互调整

输入只需一句话或粘贴、拖入图片，类似便签。IM、设备平台与普通/长截图是有默认值的可选项。生成结果是页面主体，右侧保留原始输入和好/不好评判；细分评分、记录详情、导入导出收起。标注与确认为金标分开，不因模型生成成功而自动批准。
