# IMStage 设计评审与落地边界

状态：2026-09-20，本轮用户明确授权官网深度改版及可运行 React 前端。此前“仅初始化”的阶段限制已被本次请求推进。方向仍可由用户评审调整；未接入的后端不得作为已完成能力发布。

## 产品判断

服务内容创作者、产品设计师、教学作者和评测开发者。用户有故事或示例，却要在截图工具中反复填表、重排内容。首页应先让用户看懂“可编辑的聊天故事”，工作台再提供精准控制。

产品价值来自可复用的结构化场景：改一条消息而不破坏其他内容；预览和导出消费同一场景。AI 负责理解，确定性排版负责稳定画面。每个竞品也能声称“AI 生成截图”，所以这些可观察的编辑行为比口号重要。

来源：[产品设计](https://app.notion.com/p/b87d15336ca94d3d9eabf1eaba99f1ce)、[Agent 设计](https://app.notion.com/p/18474927d567436a91000fff0f109751)、[用户故事](https://app.notion.com/p/6db32bcb104246699f778734eb3dfc4a)。已确认方向：优先微信和小红书，Web 免费，API/MCP 托管收费方案待定；云端素材长期保留是方向，尚未实现。水印默认关闭、可开启。

## 原稿审查

有效：深色/朱橙识别、语义导航、场景增删、消息编辑、素材导入、结构查看和导出路径。

问题：首屏断句失衡，巨大空白挤压产品内容；样例聊天讨论工具自身而非用户故事；工作台直接展开低频表单；平台与当前微信/小红书优先级不同；本地保存与真实服务状态容易混淆。原稿保留在 OpenDesign，不覆盖源文件及历史。

## 设计树

- D0：让用户看懂、改好、带走一个聊天故事。
- D1-A 对话导演台：用户控制剧本，空间采用编辑台、画面和轨道；内容优先展示可修改的因果。反参考：密集开发控制面板。
- D1-B 场景作品集：从成品选择表达，采用作品网格和轻盈画布；签名操作为挑选场景再展开。反参考：通用模板商城。
- D2-A1：产品证明在首屏 → 场景灵感 → 精准编辑 → 开放数据 → FAQ → 创作入口。
- D2-A2：场景库先行 → 故事筛选 → 结果放大 → 进入编辑器。挑战者更易浏览，但首次访问不能直接理解编辑价值。
- D3：已渲染深色导演台 A 与浅色作品集 B。A 保留原稿品牌连续性，以输入/结果并列暴露编辑机制；B 的多张倾斜手机抢占空间，且看不到修改过程。选 A，保留 B 作为创作者倾向更强时的候选。用户偏好优先于本次判断。
- D4：深灰中性色、朱橙动作色、原稿 Syne 英文字标、系统中文字体、8/16/24/40/64 间距节奏。标题采用完整语义分行；四种结构：舞台、作品排布、编辑演示、接入表格。手机平台颜色属于产品输出，不是官网品牌色。
- D5：焦点、按钮反馈、选中消息边界、移动端切换与 reduced-motion 支持。先修结构，再调细节。

相对判断：A 在产品机制可见性 +2、五秒理解 +1、品牌连续性 +1；B 在轻盈感 +1。这里只是截图的相对评审，不以主观绝对分数宣称设计质量。

参考机制：[Screen Studio](https://screen.studio/) 先展示可带走的作品；[tldraw](https://www.tldraw.com/) 和 [Excalidraw](https://excalidraw.com/) 提供直接进入画布的体验。仅提取入口与结果展示机制，不复制整套视觉。

## 如何获得真实 UI

1. 建立参考矩阵：平台 × iOS/Android × App 版本 × 浅/深色 × 单聊/群聊 × 消息状态。每套模板固定一个版本，禁止混合规则。
2. 用自己的测试账号与合成对话在真实 App 采集截图；覆盖文字换行、图片比例、语音时长、定位、撤回、系统事件、红包/转账状态、刘海/安全区、字体缩放。无权获取的样本标为缺失，不凭空补齐。
3. 记录设备型号、逻辑尺寸/像素比例、系统/App 版本、语言、字体大小、采集日期与来源授权。原始私有截图仅存 `.local/` 或后续受控素材库，公开仓库只放可再分发的合成基准。
4. 以真实截图测量组件，建立导航栏、头像、气泡、时间、卡片、输入栏的模板 token；系统框架参考 [Apple Design Resources](https://developer.apple.com/design/resources/)，平台专属组件以实际 App 为准。官方设计资源不是微信或小红书的完整 UI。
5. 同一合成场景在真实 App 与渲染器分别出图，固定字体/浏览器/比例后做叠图与像素差异，再人工检查文本、顺序和关键状态。通过前称“风格预览”，不宣称像素级还原。

当前缺口：本轮没有用户授权的真实 App 参考截图，微信/小红书模板为可编辑的视觉近似。AI 生图可制作聊天中的素材，不能替代整个聊天 UI 的确定性渲染。

## 前端范围

本轮交付官网、场景库、浏览器本地工作台、接入说明。实现可见消息修改、增加/删除、撤销、模板切换、本机草稿及图片导出。自由自然语言生成、截图理解、服务端持久化、真实 MCP/API、账号计费暂未实现；入口应说明状态并给出当前可执行动作。

测试必须分别检查：功能闭环、移动布局、键盘操作、错误恢复、导出文件与实际场景。截图仅证明前端呈现，不能证明真实平台一致性或后端已部署。

技术依据：[React + Vite](https://react.dev/learn/build-a-react-app-from-scratch)、[Vite Guide](https://vite.dev/guide/)。此应用采用静态 SPA，SSR、生产索引与后端服务在上线阶段另验收。
