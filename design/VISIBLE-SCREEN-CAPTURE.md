# 普通截图：所见区域即导出区域

2026-09-21。用户要求在固定设备窗口内拖动聊天内容，COPY / 下载得到当前可见的一屏。

- 普通截图中只有消息区滚动；状态栏、聊天标题、输入栏和水印固定。支持滚轮、触控板、原生触摸滑动和鼠标按住上下拖动；滚动条不进入截图。
- 鼠标拖动根据画布缩放反算场景坐标，移动阈值区分拖动和点击；拖动结束不会误选消息，之后单击仍能编辑。键盘可聚焦消息区滚动。
- 元素列表定位屏外消息时滚动到对应位置，保持普通截图模式。
- 复制和下载点击时捕获消息区的逻辑 scrollTop。共享渲染路径将该偏移转换为导出内容的平移，避免 DOM 克隆丢失 scrollTop 而导出顶部。外壳和消息背景固定，截取使用设备原生像素，预览缩放不影响导出分辨率。
- 长截图显式使用零偏移并展开所有内容，保留现有行为。原图保留编辑模式仍使用其已有图片渲染路径，本次针对结构化聊天的普通截图窗口。

## 验证

`npm run build` / TypeScript / git diff 检查通过。36 项受影响浏览器测试全部通过，包括原有编辑、图片输入、设备与复制回归，以及 4 项本轮新验收：

1. 缩小画布后鼠标拖动距离正确，滚轮继续滚动，标题和输入栏不动；拖动不误触选择，下一次点击仍可编辑。
2. 中间位置 scrollTop=543 的浏览器可见消息区域与 PNG 对齐；错误的顶部截图是明确的失败对照。固定标题/输入栏一致；实际 PNG 剪贴板与下载具有相同内容和尺寸（iPhone 17 Pro：1206 × 2622）。
3. 选择第 22 条消息会滚动显示，仍为普通截图。
4. 手机触摸上下滑动使用 Chromium 原生触摸事件，保持设备窗口固定。

像素比较排除仅预览存在的机身圆角，消息内部使用 1 px 模糊消除字体抗锯齿差异；固定部件和复制/下载对比允许不足 0.001% 像素的 SVG 光栅化差异。没有通过放宽位置断言掩盖裁切错误。长截图从顶部与滚动后分别导出也一致。

证据为合成对话，见 `evidence/visible-crop/preview.png`、`export.png`、`touch.png`；未保存用户原始截图或私人对话。本轮没有新增物理 iPhone / Safari 验证声明。
