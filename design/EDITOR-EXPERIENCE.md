# 对话工作台：元素编辑与 AI 协作

2026-09-21。基于截图实际运行的 `core-web-auth` 版本（3ae0e25）实现；主目录的旧版并不包含截图中的 Agent 工作台。此次未使用 Pi。

## 已实现

- 将创作助手、画布和元素属性整理为稳定三栏。左侧切换 AI / 元素列表，右侧切换属性 / AI 修改。短窗口下输入区固定可见，属性区独立滚动；移动端通过视图切换与可关闭编辑面板操作。
- 画布按可用宽高自适应，支持放大、缩小、复位及收起左栏。预览缩放不改变设备或导出分辨率。
- 可从画布或列表选择消息、头像、标题、状态、日期及输入栏；列表可定位普通截图范围外的消息并自动展开长图。原截图模式列出实际编辑层。
- 属性按内容、素材、引用、外观、操作分组。支持发送者、时间、消息类型、配图、相册说明、背景、字体和尺寸；增加消息复制、下移、删除、重做及连续输入合并撤销。
- 左侧可明确切换整个对话 / 选中元素；右侧 AI 始终显示目标范围。两者复用现有 Agent 协议。局部修改不消费或清除左侧尚未提交的参考图。
- 消息与头像使用独立键盘按钮。导出保持无选中框的共享渲染路径。

## 验证

- `npm run build`：通过。
- `npm test`：288 / 288 通过。
- 48 项浏览器测试：全部通过。覆盖原有官网/编辑器、账号保存互斥、失败与取消、设备尺寸、PNG 下载、移动端、深浅主题、WCAG A/AA 自动检查，以及本轮新增的属性/排序/范围/键盘/撤销/长对话定位。
- 浏览器测试在隔离账户数据库与合成内容上运行；测试中的 Agent 响应为协议桩，不据此声称真实模型效果已验收。
- 人工查看桌面浅色、深色与移动端截图。证据在 `design/evidence/editor-experience/`；图片使用合成场景。

## 实现依据

- [React Effect 的外部连接与清理](https://react.dev/reference/react/useEffect#connecting-to-an-external-system)：订阅并清理窗口、媒体条件与尺寸变化。
- [ResizeObserver](https://developer.mozilla.org/en-US/docs/Web/API/ResizeObserver)：测量独立视口，避免被缩放的子元素形成尺寸反馈循环。

本轮交付为本机编辑体验升级。截图内的第三方平台外观属于现有项目模板，不新增平台版本保真声明；公网 Vercel 与主分支发布状态另行核验。
