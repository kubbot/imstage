# 从输入框开始的 IMStage

2026-09-20 · 第二轮前端设计。用户提出：输入“我和 Elon Musk 在明天一起去火星漫游”，随后在聊天画面里看到双方对话、火星定位、合影，以及有真实 X 来源的头像。

## 产品与交互决策

1. 首页直接可输入并提交场景，主导航进入 `/#/create`；人物/时间/消息等表单留在次级细节编辑器。第一次创作不要求先理解场景数据结构。
2. 右侧持续渲染结构化场景。文字可以逐段出现，照片就绪后填入对应消息；不把整个聊天截图交给图像模型生成，避免文字、头像、消息顺序不可编辑。
3. 展示当前步骤而不编造完成百分比。支持停止、保留部分结果、失败重试；终止旧请求后不接受迟到事件。
4. 生成后可点选一句话或一个地点直接修改，切换平台保留内容，再导出普通图/长图。进入原工作台前保护已有草稿，允许先下载备份。
5. 素材来源单独可查看：X 头像参考、示意定位、AI 合成照片各有来源；用户没有提供本人照片时，同行者明确为虚构人物。

移动端采用“写下场景 / 实时画面”切换；双主题沿用用户此前选择：默认跟随系统，也能手动覆盖。

## 本次已实现

- 输入驱动的首页和独立创作页，火星示例的逐条/逐段回放，异步图片占位与填入。
- 与原工作台共享 `SceneView`、数据验证、图片导出和草稿契约。
- 取消、错误、重试、精准编辑、平台切换、来源说明和真实 PNG 下载。
- 真实接口的浏览器 NDJSON 客户端：校验 UTF-8 分块、事件顺序、消息 ID、素材格式、大小、提前结束、终止及完成状态；不会把接口失败偷偷替换为示例。
- 新增火星合影为实际 imagegen 输出；X 头像为有采集日期的 CDN 副本。详见 [素材与最终生成提示词](../apps/web/public/assets/README.md)。

**示例模式是预设故事与素材的回放，不是任意自然语言的实时 AI 生成。** 非火星提示词不会被静默替换成火星内容。

## 真实生成仍需完成的连接

本轮对项目已有的腾讯云 TokenHub 凭据记录做了最小只读验证，模型目录请求返回 HTTP 401；没有因此认定记录是有效 API Key，也没有把凭据放进浏览器或仓库。

当前没有服务端 `POST /api/scenes/stream`。要让自由输入真实生成，需要有效服务端凭据及模型选择，再实现服务端的场景规划、文本流、头像检索和图片生成编排。本轮客户端契约验证使用合成接口响应，不能当作真实模型验收。

建议后续服务流程：

```text
一句话 + 可选本人参考图
  → 场景规划：人物、日期、地点、消息节奏
  → 对话事件流 ────────────────────────┐
  → 头像来源检索 → 来源/采集日期 → 素材事件 │
  → 合影生成 → 成功/失败/重试 → 素材事件    │
                                      ↓
                         同一份 Scene → 确定性 UI → PNG
```

`明天`按用户所在时区解析；头像检索失败显示可替换占位，不能用生成头像冒充真实来源。图片生成单独失败时保留文字和地点，允许只重试失败素材。停止应同时取消服务端上游工作；客户端取消不能证明上游计费已停止。

## 事件契约

请求：`{ prompt, platform, previousScene? }`；响应：`application/x-ndjson`，每行一个事件。

- `scene`：有效的场景及人物元数据。
- `message`：按稳定 ID 插入一条消息。
- `message-delta`：追加某条消息的文本。
- `asset`：为人物头像或图片消息填入受限的 PNG/JPEG/WebP Data URL。
- `status`：理解、编排或素材阶段；只反映实际工作。
- `done`：场景有效且图片就绪，随后不得再写入事件。
- `error`：可理解的错误；不泄露上游凭据。

图片事件支持大于 1MB 的正常素材，并设单行及总响应大小上限。真实服务还需任务标识、来源元数据、重试幂等与额度约束；尚未宣称这些服务端行为已实现。

## 验证

53 项数据/协议测试通过，27 项浏览器测试通过。覆盖示例流、停止、非匹配输入、真实接口失败不回退、协议模拟响应、草稿保护、PNG 签名与尺寸、五页的 320/390/768/1440px 布局，以及浅/深色的 axe WCAG 2 A/AA 自动检查。

导出验收发现异步更新后 DOM 尚未提交，修复为仅在导出边界使用 [React `flushSync`](https://react.dev/reference/react-dom/flushSync) 提交快照。停止按钮验证发现复用表单按钮可能触发默认提交，已阻止默认行为并区分按钮身份。

证据见 [本轮截图与验收日志](evidence/prompt-first/README.md)。未验证真实 AI 供应商生成、X 实时同步或真人身份合成。
