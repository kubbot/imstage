# 左侧优先的创作工作台验收

2026-09-21。用户要求左侧成为视野与操作重点，扩大创作空间并优化布局。

## 已实现

- 桌面创作区默认从 288 px 扩至 480 px。分隔线支持拖动、方向键、Home / End；双击恢复默认。宽度在 360–640 px 内随窗口约束，并记住设置。
- 会话入口保留在顶部，去除重复面板标题；人物与项目设置折叠。对话字号与行距增大，底部输入区固定可达，可调整输入高度。
- 右侧属性默认关闭，点选元素或点击元素编辑时打开；中等窗口使用浮层，避免继续挤压创作区。
- 平板保留创作与预览；手机通过创作 / 画面切换，适配短屏与深浅主题。
- 错误提示移至工作台顶部并限制高度，解决停止生成或失败后提示遮挡发送 / 重试按钮的问题。

## 验证

`npm run build` 通过。45 项不同浏览器用例分批通过：creation-layout 5、editor-experience 6、sessions 10、projects 2、visible-crop 4、agent 9、timeline-copy 9。

验证涵盖宽度拖动 / 键盘 / 刷新恢复、按需属性编辑、桌面 / 平板 / 手机输入可达性、WCAG A / AA 自动检查、会话切换、项目保存、错误后重试、时间线，以及 PNG / 剪贴板可见范围一致性。首次回归发现的提示遮挡已修复并复测通过；项目测试同步更新了已变更的属性标签。未运行原生 iOS Simulator；这里的手机验收为浏览器视口适配。
