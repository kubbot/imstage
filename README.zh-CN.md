# IMStage

为测试、教学与评测数据集标注创作合成聊天场景。

[打开 IMStage →](https://imstage.org/?lang=zh) · [English](README.md) · [参与贡献](CONTRIBUTING.md)

> **GitHub 声明 — 仅供测试与学习。** IMStage 生成**合成聊天内容**，
> 用于软件测试、教学与评测数据集标注。**不可用于任何商业用途**。
> **反滥用：** 严禁伪造证据、欺诈、诽谤、冒充真实个人或机构，或让他人误以为
> 生成内容是真实记录。所有输出都是合成内容，不得作为真实对话的证据；
> 请使用虚构素材或你有权使用的真实素材（授权头像、真实地名均可）。
> 所有预览与导出图片都**默认**带有 **「AI生成 / 虚构」**水印；项目与画面提供水印
> 开关（默认开启），AI 不能替你修改该选择。

- **直接编辑。** 修改消息、人物、头像、时间和设备状态；支持撤销和独立的本机会话。
- **用文字创作。** 登录后，让 Agent 生成或修改合成场景。
- **复用创作。** 把可编辑画面存为模板，将姓名和照片设为变量，按项目规则批量生成差异版本。
- **导出成品。** 下载普通截图、完整长图或可编辑的 JSON。所有 PNG（含裁切与 MCP 渲染）默认带有虚构水印。
- **接入自己的工具。** 自托管账号 API 与 Agent，或通过认证后的 MCP 服务创建和渲染场景。

画面按所选聊天模板渲染——IMStage 通用，以及微信、WhatsApp、iMessage、Instagram、
小红书、Slack。均为合成内容的风格预览：与任何聊天平台无关，不使用第三方商标，
不做像素级界面克隆。

## 本地运行

需要 Node.js **22.18–22.x**。

```sh
npm ci
npm run dev
```

打开 [localhost:4417](http://127.0.0.1:4417)。生产构建与启动：

```sh
npm run build
npm start
```

使用 Agent 需要在服务端配置模型密钥。手动编辑和 PNG 导出不需要模型密钥。

## 部署与接入

官网前端部署在 Vercel，账号、作品保存与 Agent 请求由持久化服务器处理。模型密钥仅保存在服务端。
本机会话保存在当前浏览器。

通过[账号连接页面](https://imstage.org/#/connect)接入 ChatGPT。账号 MCP（`/api/mcp`）采用
OAuth 登录授权，与网页“我的作品”共用作品；自托管 `/mcp` 保留管理员实例令牌和独立场景库。

**审计与留存。** 每一次托管生成（网页 Agent、项目批量、头像生成、两个 MCP 保存的 AI 内容
以及托管渲染输出）都会写入一条持久审计记录：运行 id、时间、账号 id、策略版本、状态与
场景哈希——绝不包含提示词原文、截图或令牌；哈希只是摘要，本身不保存原文内容。
审计记录的主保留期为 **90 天**，由周期性运行的清理任务删除（最长约 6 小时延迟）。
运营数据（保存的作品、项目、项目规则、批量提示词）按账号单独存储；部署侧备份另有策略
（保留 **14 个版本**），并非所有副本都在第 90 天消失。
**精确局限：** 匿名的本地编辑与 PNG 导出不上传场景内容，**不会**产生服务端审计记录
（页面仍会加载静态资源，服务器仍保留常规访问日志）；默认开启的水印由渲染器绘制，
随每张导出图片携带。详见[隐私说明](https://imstage.org/#/privacy)
与[使用条款](https://imstage.org/#/terms)。

## 开发验证

```sh
npm test
npm run test:ui  # Playwright，默认使用已安装的 Google Chrome
```

使用自带 Chromium：先运行 `npx playwright install chromium`，再执行
`IMSTAGE_BROWSER=chromium npm run test:ui`。开发约定见[贡献指南](CONTRIBUTING.md)。

内置对话与头像为虚构素材；用户上传的头像与地名须为虚构或已获授权。支付、转账、红包、
余额类消息类型已移除；真实截图参考编辑在所有公开入口停用（内部离线评测工具保留研究代码，
但公开不可达）。该限制不保证任意上传图片的像素内容本身不可能是一张截图——请只上传虚构
或已获授权的素材。
